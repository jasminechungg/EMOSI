# Introduction

Understanding emotions plays an important role in communication, learning, behaviour, and overall well-being. However, some individuals may face challenges in expressing or communicating their emotional states effectively. This challenge can be more apparent among children with emotional, behavioural, developmental, or communication difficulties, where emotions may not always be clearly conveyed through verbal communication or observable behaviours alone.

EmoSI was developed as a cloud-based emotion monitoring system that integrates wearable physiological sensing, machine learning, and real-time data visualization. The system uses the EmotiBit wearable device to collect physiological signals such as photoplethysmography (PPG), electrodermal activity (EDA), body temperature, and motion data. These signals are transmitted to cloud services, processed using machine learning models, and visualized through an interactive dashboard.

It is important to note that this project represents a foundational stage rather than a completed child assessment solution. The machine learning model used in the current implementation was trained using publicly available physiological datasets and has not been specifically trained or validated using data collected from children. As a result, the system should not be interpreted as a clinical, diagnostic, or validated tool for assessing children's emotional states.

To develop a reliable child-focused emotional assessment system, future work would require extensive data collection involving children from the intended target population, including those with emotional, behavioural, developmental, or communication challenges. Additional model training, tuning, validation studies, ethical approvals, and collaboration with domain experts would also be necessary to ensure accuracy, safety, and relevance for real-world use.

Despite these limitations, the platform demonstrates the feasibility of combining wearable physiological sensing, cloud computing, and machine learning for emotion-related analysis. The architecture developed in this project may serve as a foundation for future applications beyond child emotional assessment. Potential use cases include communication support systems, emotion-aware learning environments, stress monitoring, behavioural research, language learning studies, and other domains where physiological responses may provide additional insight into an individual's internal state.

The primary contribution of EmoSI is the development of an end-to-end cloud-based platform capable of acquiring physiological signals, processing data in real time, performing machine learning inference, and presenting interpretable results through a centralized dashboard. This foundation can support future research and development efforts that require objective physiological data to complement traditional observation and self-reporting methods.
