# EmoSI

Cloud-Based Emotion Monitoring System Using EmotiBit, AWS Cloud Services, Machine Learning, and Real-Time Dashboard Visualization.

## Project Overview

EmoSI is a cloud-based emotion monitoring system that integrates wearable physiological sensing, cloud computing, machine learning, and data visualization to monitor emotional states in real time.

The system collects physiological signals from the EmotiBit wearable device, transmits the data through AWS cloud services, performs emotion recognition using machine learning, and presents the results through a Streamlit dashboard.

## Features

- Real-time physiological monitoring
- Cloud-based data processing
- Machine learning emotion recognition
- AWS-powered architecture
- Interactive dashboard visualization
