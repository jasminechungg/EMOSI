### Dashboard Code Disclaimer

The dashboard code provided in this repository is intended for prototype demonstration purposes. Some UI elements and displayed values are hardcoded to help users understand the system's interface, features, and workflow when exploring the code in their own environment.

To use the dashboard as a fully functional system, users will need to configure their own database connections and AWS services to retrieve and display actual data. Certain configurations and credentials have been excluded or modified to protect confidential information and maintain security.
